# SimTools Superpowers Workflows

This directory contains project-local Superpowers-style workflows for SimTools.
They are not installed as global Codex skills. They translate the reusable
Superpowers discipline into SimTools-specific guardrails that are already owned
by `AGENTS.md`.

Use these workflows when a task matches their frontmatter description:

- `simtools-add-adapter/`: add a new simulator through manifest + adapter.
- `simtools-review-harden/`: review and harden the scaffold without adding a
  large feature.

Global Superpowers skills still apply when available. These project workflows
add SimTools-specific checklists and verification commands.
